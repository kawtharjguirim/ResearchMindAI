\abstract{
\textbf{Background:} Polygenic risk score (PRS) tools differ substantially in statistical assumptions, input requirements, computational cost, and implementation complexity. Direct comparison remains difficult because existing benchmarks use inconsistent preprocessing, evaluate few tools, and rarely account for practical constraints such as installation failures, runtime, or input-format incompatibilities. 
%Tool selection is consequently guided by convention rather than systematic evidence.

\textbf{Results:} We developed a harmonized benchmarking framework for implementation-aware evaluation of 46 PRS tools across seven binary phenotypes from the UK Biobank and one continuous phenotype (Height). The framework standardizes preprocessing, high-performance computing execution, five-fold cross-validation, and evaluation under three model configurations: null, PRS-only, and PRS plus covariates. A Friedman test across 40 phenotype-fold combinations confirmed significant differences in tool rankings ($\chi^2 = 102.29$, $p = 2.57 \times 10^{-11}$), with seven different tools emerging as phenotype-specific top performers. Tools ranking most consistently across traits included LDpred2-Lassosum2, PRSice-2, and LDAK-GWAS, though no method was uniformly optimal. A substantial proportion of tools failed under at least one phenotype due to insufficient SNP overlap, invalid heritability estimates, or reference-panel dependencies. Runtime ranged from 0.023 hours for GEMMA-LM to over 33 hours for HAIL.

\textbf{Conclusions:} This study provides a reproducible, implementation-aware benchmarking framework for comparative PRS tool evaluation rather than a definitive ranking of superior methods. Performance is strongly context-dependent and shaped by phenotype architecture, preprocessing choices, covariate structure, and software robustness. The framework and associated code are publicly available as a reusable resource for future benchmarking across broader cohorts and diverse ancestry groups.
}

\section*{Introduction}
Polygenic risk scores (PRS) quantify an individual’s genetic predisposition to complex traits, diseases, and related outcomes by aggregating effect-size estimates from genome-wide association studies (GWAS) across many single-nucleotide polymorphisms (SNPs)~\cite{Choi2020,Lewis2020,RN8133,Nakase2024}. PRS construction can involve multiple data sources, including GWAS summary statistics~\cite{Nakase2024}, genotype data~\cite{Hui2023}, covariates such as age, sex, and environmental factors~\cite{Hui2023}, reference panels~\cite{Loh2023}, linkage disequilibrium (LD) information~\cite{Vilhjalmsson2015}, and, in some pipelines, GWAS from related traits or populations~\cite{Zhuang2024}. Although the underlying PRS formulation is conceptually simple, accurate score construction depends on how SNP effects ($\beta$) or posterior quantities are estimated under different modelling assumptions~\cite{ZHU20201557,Barry2022}. This has led to a broad range of PRS methods, including linear mixed models (LMMs), generalized linear mixed models for non-normal traits, Bayesian variable-selection and shrinkage approaches such as Bayesian variable selection regression (BVSR) and Bayesian sparse linear mixed models (BSLMM), sparsity-based models, and cross-trait or multi-ancestry extensions~\cite{Loh2023,ZHU20201557,Barry2022}.

As GWAS sample sizes and the availability of public summary statistics have increased, the number of computational tools for PRS construction has also increased~\cite{Choi2020,Lewis2020}. These tools differ in statistical assumptions, treatment of LD~\cite{Vilhjalmsson2015}, use of functional annotation~\cite{Zhuang2024}, reliance on individual-level versus summary-level data~\cite{Hui2023}, computational implementation~\cite{ZHU20201557,Barry2022}, and the type of phenotype or study design for which they are best suited~\cite{Ma2021,Zhang2021}. As a result, researchers face a broad and heterogeneous PRS software landscape when selecting an appropriate method for a given analysis.

Several comparative studies have evaluated subsets of PRS methods and shown that performance depends strongly on phenotype architecture, training data characteristics, sample composition, and modelling choices~\cite{Ma2021,Zhang2021}. However, direct comparison across the expanding PRS ecosystem remains difficult. Existing benchmarks often evaluate only a limited number of tools, use heterogeneous preprocessing and validation strategies, or assess performance in narrowly defined settings~\cite{Ma2021,Zhang2021}. Most studies emphasize predictive performance alone and pay limited attention to practical implementation factors, including installation complexity, software dependencies, input-format requirements, runtime, memory usage, reference-panel needs, and failure behaviour under real-data constraints. These operational characteristics can strongly influence whether a method is practical for large-scale analyses, particularly in high-performance computing (HPC) environments and multi-phenotype benchmarking studies.

Another challenge is that comparative performance may reflect not only the PRS method itself, but also the analytical setting in which the score is evaluated. Covariate structure, phenotype type, preprocessing choices, and hyperparameter selection can all influence downstream prediction~\cite{Hui2023,Ma2021,Zhang2021}. Benchmarks that report only a single final performance measure may therefore obscure whether observed differences arise from the PRS model itself or from the surrounding modelling pipeline. A fair comparison requires standardized preprocessing, consistent validation, and explicit separation of null, PRS-only, and PRS-plus-covariate models.

To address these gaps, we developed a harmonized benchmarking framework for implementation-aware comparative evaluation of PRS tools under standardized preprocessing, execution, and validation conditions. Using this framework, we benchmarked 46 PRS tools across seven binary phenotypes from the UK Biobank and one continuous phenotype (Height). The framework integrates data transformation, tool-specific execution on HPC systems, five-fold cross-validation, hyperparameter exploration, and unified downstream evaluation. Each phenotype was evaluated under three model configurations: a null model, a pure PRS model, and a full model combining PRS with covariates. For binary phenotypes, predictive performance was assessed using the area under the receiver operating characteristic curve (AUC), whereas for Height, performance was assessed using explained variance ($R^2$).

This study makes three main contributions. First, it establishes a reproducible benchmarking framework that standardizes data preparation, execution, and evaluation across a large and heterogeneous set of PRS tools. Second, it provides a comparative analysis across phenotypes, showing that PRS performance varies across traits and analytical settings, with no single method consistently outperforming all others. Third, it documents implementation-aware aspects of PRS benchmarking, including runtime, memory usage, installation requirements, input dependencies, and structured failure modes. Together, these features position the study as a practical resource for transparent and reproducible PRS benchmarking rather than as a definitive ranking of universally superior tools. The full framework, code, and documentation are publicly available at \url{https://muhammadmuneeb007.github.io/PRSTools/Introduction.html}.

\section*{Methodology}
\label{Methodology}

\subsection*{Dataset}
We benchmarked 46 PRS tools across eight phenotypes, comprising seven binary phenotypes from the UK Biobank and one continuous phenotype (Height). For the binary phenotypes, genotype data were extracted for 733 participants, and the corresponding GWAS summary statistics were obtained from the GWAS Catalog (\url{https://www.ebi.ac.uk/gwas/}). The genotype dataset included individuals with reported comorbid conditions, including hypertension, asthma, depression, osteoarthritis, high cholesterol, irritable bowel syndrome, hypothyroidism, hay fever, migraine, and gastric reflux, together with 135 nuclear magnetic resonance (NMR) metabolomic biomarkers. These biomarkers and comorbid conditions were used as covariates in downstream predictive models.

For the continuous Height phenotype, we used the GWAS and genotype data provided in the PRS tutorial dataset described by Choi et al.~\cite{Choi2020}, available at \url{https://choishingwan.github.io/PRS-Tutorial/base/}. For this dataset, age and sex were used as covariates.




% We evaluated 46 PRS tools identified from published studies \cite{Ma2021}. 


  


 



\subsection*{Quality control and harmonization}
GWAS summary statistics for all phenotypes were obtained from the GWAS Catalog summary statistics resource (\url{https://www.ebi.ac.uk/gwas/downloads/summary-statistics}), and the corresponding study-specific summary files are listed in Supplementary Table~1 (\textbf{GWAS Information}). To enable consistent benchmarking across tools, GWAS summary statistics and genotype data were harmonized before tool-specific execution. GWAS files were standardized using GWASPokerforPRS (\url{https://github.com/MuhammadMuneeb007/GWASPokerforPRS/blob/main/README.md}) to retain the fields required for PRS construction, including chromosome, base-pair position, SNP identifier, p-value, effect size or odds ratio, reference allele, alternative allele, and minor allele frequency. Genome builds were matched between the GWAS and genotype datasets before downstream analysis. 

Quality control was then applied to both GWAS and genotype data. For GWAS summary statistics, SNPs were retained if the minor allele frequency (MAF) was greater than 0.01 and the imputation INFO score was greater than 0.8. Ambiguous SNPs and SNPs with missing alleles, including complementary A/T and C/G variants, were removed to reduce strand-alignment errors. For genotype data, we applied filters of MAF $> 0.01$, Hardy--Weinberg equilibrium threshold $p > 1 \times 10^{-6}$, genotype missingness $< 0.1$, individual missingness $< 0.1$, and relatedness cutoff $< 0.125$. After quality control, the final genotype dataset for the seven binary phenotypes contained approximately 600{,}000 SNPs and 152 covariates, whereas the Height dataset contained 551{,}892 SNPs and two covariates.



%PRS tools also differed in their input requirements. Some methods, such as XP-BLUP and EB-PRS, used only GWAS summary statistics to estimate effect sizes, whereas others, such as PRSice-2, required both GWAS summary statistics and training genotype data. GEMMA used genotype data, whereas GCTB required genotype data, GWAS summary statistics, and a reference panel. 


\subsection*{Benchmarking workflow/execution framework}

We used a harmonized benchmarking framework in which common preprocessing steps were standardized while allowing tool-specific execution paths. PRS tools differed substantially in their assumptions, accepted inputs, software dependencies, and computational requirements. To support fair comparison, each tool was installed, configured, and executed under a standardized workflow that included data preparation, parameter definition, PRS generation, downstream model fitting, and fold-wise performance measurement.

Following preprocessing, genotype and GWAS data were reformatted to satisfy tool-specific input requirements. Some tools required Plink binary files, whereas others required dosage files or exact SNP correspondence between GWAS and genotype datasets. Based on input structure, tools were broadly grouped into four categories: (i) methods using GWAS summary statistics only, (ii) methods using both GWAS summary statistics and genotype data, (iii) methods using genotype data only, and (iv) cross-trait or multi-ancestry methods using GWAS from multiple populations or diseases. Some methods, such as NPS and CTPR, imposed strict input requirements, including a genotype rate equal to 1 and exact SNP matching between the GWAS and genotype files. Detailed information on tool-specific input requirements, including GWAS data, genotype data, covariates, and reference panels, is provided in Supplementary Table~2 (\textbf{PRS tool characteristics}). Installation, formatting, and execution details for each tool are available in the online documentation at \url{https://muhammadmuneeb007.github.io/PRSTools/Introduction.html}.

\subsection*{Cross-validation and hyperparameter search}

All PRS tools were evaluated within a five-fold cross-validation framework. For each phenotype, the data were split into training and test sets. Tool fitting, hyperparameter exploration, and model selection were performed using the training data, and the resulting SNP weights or effect sizes were then applied to the corresponding test set. This design was used to reduce information leakage and ensure that reported performance reflected out-of-sample evaluation.

Hyperparameters explored in benchmarking included clumping, pruning, principal component adjustment, p-value thresholds, reference-panel choices, and method-specific options such as heritability estimation. For clumping, we used a p-value threshold of 1, an LD threshold of 0.1, and a distance threshold of 200. For pruning, we used a window size of 200, a step size of 50, and an LD threshold of 0.25. PRS were evaluated across 20 logarithmically spaced p-value thresholds ranging from $10^{-10}$ to 1. Additional tool-specific hyperparameters, including alternative reference panels, alternative heritability estimators, and different clumping or pruning settings, were explored where relevant.

\subsection*{Model configurations}

Each phenotype was evaluated under three model configurations:

\begin{enumerate}
    \item \textbf{Null model:} covariates and principal components (PCs) only;
    \item \textbf{PRS-only model:} PRS only;
    \item \textbf{Full model:} PRS with covariates and PCs.
\end{enumerate}

This design allowed us to distinguish the contribution of the PRS from that of the broader covariate structure. For the binary phenotypes, the covariate set included metabolomic biomarkers, comorbid conditions, and principal components. For Height, the covariates included age, sex, and principal components.

\subsection*{Performance evaluation}

For each trained model, PRS values were calculated by applying estimated SNP effect sizes to the test genotype data using Plink \texttt{----score}~\cite{Choi2020}. PRS was computed as

\begin{equation}
PRS = \sum_{i=1}^{n} \left( \beta_i \times G_i \right),
\label{Plinkequation}
\end{equation}

where $\beta_i$ denotes the estimated effect size of the $i$-th SNP and $G_i \in \{0,1,2\}$ denotes the genotype count for that SNP. The total number of SNPs included in scoring is represented by $n$.

For binary phenotypes, predictive performance was evaluated using logistic regression and quantified using the area under the receiver operating characteristic curve (AUC)~\cite{Sperandei2014}. For the continuous Height phenotype, predictive performance was evaluated using ordinary least squares regression and quantified using explained variance ($R^2$)~\cite{Zdaniuk2014}. Performance was recorded on both training and test sets for all retained p-value thresholds and tool-specific hyperparameter combinations across the five folds.

\subsection*{Hyperparameter summarization rule}

To summarize the large hyperparameter search space consistently, we applied a predefined $\delta$-constrained selection rule to each tool and phenotype. For binary phenotypes, $\delta$ was set to 0.05 AUC, and for Height, $\delta$ was set to 0.03 in explained variance ($R^2$). Among candidate configurations with an absolute train--test performance difference below $\delta$, we selected the configuration with the highest combined training and test performance. If no configuration satisfied this criterion, we selected the configuration with the smallest train--test gap. Thus, the reported full-model results correspond to the selected stable configuration and not necessarily to the configuration with the single highest test performance. 

\subsection*{Statistical comparison of PRS tools}

To assess whether PRS tool performance differed significantly across phenotypes, we performed a global ranking-based comparison using fold-level test performance from the full model. For each phenotype and fold, tools were ranked according to test performance, with rank 1 assigned to the best-performing tool. These rankings were then compared across phenotype--fold combinations using the Friedman test, a non-parametric repeated-measures method for comparing multiple algorithms across multiple datasets.

When the Friedman test indicated significant differences, post hoc pairwise comparisons were performed using the Nemenyi procedure. Multiple testing correction was applied using the Benjamini--Hochberg false discovery rate (FDR) method. Average ranks across all phenotype--fold combinations were used to identify tools that performed consistently well.

Predictive performance varied substantially across both tools and phenotypes, indicating that no single PRS method consistently achieved the strongest results in all settings.

At the phenotype level, the best-performing methods differed across traits. LDpred-gibbs performed best for Asthma (AUC~=~0.60), LDAK-GWAS for Height ($R^2$~=~0.35), PolyPred for Depression (AUC~=~0.64), BOLT-LMM for Gastro-oesophageal Reflux (AUC~=~0.75) and Hypothyroidism (AUC~=~0.67), PRSice-2 for High Cholesterol (AUC~=~0.93), MTG2 for Irritable Bowel Syndrome (IBS) (AUC~=~0.67), and GEMMA-LM for Migraine (AUC~=~0.63). These results are consistent with previous observations that PRS tool performance is phenotype-dependent and influenced by trait architecture and evaluation design~\cite{Ma2021}.

Although several methods performed strongly across multiple phenotypes, the relative ranking of tools changed markedly by trait/phenotype/disease. This phenotype dependence was also reflected in the distribution of top-performing tools across phenotypes, with no single method dominating all analyses. Taken together, these findings support interpretation of the benchmark as a comparative multi-phenotype evaluation framework rather than a definitive ranking of PRS tools.  


 

The following analyses were conducted on the Height phenotype but can be extended to other phenotypes. Tools were evaluated based on execution time (hours) and memory usage (MB). GEMMA-LM was the most efficient (0.023 hours, 1.79 MB), ideal for high-throughput and memory-constrained analyses. HAIL (36.37 hours) and PleioPred (14.03 hours, 34.41 MB) were the least efficient, though later effective for continuous phenotypes (Supplementary material \textbf{(Execution Time - Height)}). 

As the p-value increased, training performance improved for all tools. However, tools like GEMMA-LM, GEMMA-LMM, and XPBLUP maintained high performance with small p-values, likely due to overfitting. Tools like AnnoPred, Plink, and PleioPred showed consistent performance increases with higher p-values. A box plot comparing the training and testing performance of the null model, pure PRS model, and the best model was plotted (Figure \ref{Figure1}: b). LDAK-GenotypeData, BOLT-LMM, GEMMA models, and MTG2 exhibited higher training performance compared to testing performance, likely due to overfitting. GCTA, Lassosum, LDpred-2, PRScs, and VIPRS showed the lowest variation in performance, indicating stability in predicting continuous phenotypes. Plink’s performance across various p-values for the Height phenotype (Figure \ref{Figure1}: c) demonstrated that performance improved as the p-value increased, with a decrease in variance explained by pure PRS. Combining the pure PRS with covariates improved both training and testing performance, a trend observed across most tools and phenotypes. PRS tools estimate posterior probabilities using beta values, genotype data, covariates, and reference panels. Tools relying on training genotype data for beta values cluster closely in the Multidimensional Scaling (MDS) plot. LDpred-based tools (LDpred2\_inf, LDpred2\_grid, LDpred2\_auto, LDpred2\_lassosum2) exhibit similar beta distributions and are grouped together, as are tools like PleioPred, AnnoPred, Lassosum, and LDAK (Figure \ref{Figure1}: d and e). Tools in the top-right and bottom-left corners of the MDS plot tend to show higher explained variance. Bayesian approaches (DBSLMM, GCTB-SBayesR, GCTB-SBayesRC) show weaker correlations with linear model-based tools (Plink, PRSice-2), while Lassosum, GCTB-SBayesR, and LDAK-GWAS show strong positive correlations. LDpred2 and LDpred methods have negative correlations with other tools. These correlation patterns highlight methodological differences between linear and Bayesian approaches, providing valuable insights for tool selection and future methodology development (Supplementary Material \textbf{(Beta's Correlation - Height)}). Tools using all SNPs (p-value = 1), such as LDAK-GWAS and Lassosum, show higher performance. However, tools like JAMPred and BOLT-LMM, which use fewer SNPs, also perform well, suggesting that selective SNP approaches can be beneficial.

This study evaluates several PRS tools based on execution time, memory consumption, and performance across two datasets. The findings emphasize that the optimal tool for a specific phenotype cannot always be predicted due to various factors, including differences in cross-validation methods, data sampling, and dataset-specific hyperparameters \cite{Ma2021}. However, one can find a tool that has generalized performance across diverse phenotypes \cite{Zhang2021}. Key issues encountered when testing these tools included input data variability, necessitating extensive preprocessing. We recommend using the Plink format for consistency, as it is most commonly supported. Furthermore, tools often required specific GWAS file formats, and several tools depended on external software and dependencies, complicating the implementation. Some tools had strict data requirements, such as no missing values and exact SNP matching, and others (e.g., GCTB) required large external reference panels. Limited end-to-end pipelines and insufficient documentation further hindered efficient testing. To address these challenges, we provided resources to assist in the development of more robust PRS tools (\url{https://muhammadmuneeb007.github.io/PRSTools/Introduction.html}). This research presents a framework for exploring the impact of hyperparameters on PRS performance, offering insights into their effect on genotype-phenotype prediction. By adjusting hyperparameters and analyzing posterior $\beta$ values, researchers can better understand genetic effect estimates and compare new models with existing ones. Additionally, the framework allows for benchmarking PRS tools across multiple datasets, supporting the comparison of identical models across different tools and aiding in tool selection. The provided methodology serves as a foundation for developing new PRS models and conducting comparative analyses among PRS tools.

\subsection*{PRS performance relative to the null model}

To assess whether polygenic risk scores (PRS) provided predictive value beyond baseline covariates, we compared the full model (PRS + covariates + principal components) with a phenotype-specific null model containing covariates and principal components only. For each PRS tool and phenotype, hyperparameter configurations were selected using the predefined $\delta$-constrained procedure described in the Methods. Briefly, among candidate settings with an acceptable train--test gap, the configuration with the highest combined training and test performance was selected; if no configuration satisfied the $\delta$ threshold, the configuration with the smallest train--test gap was retained. The selected configuration was then summarized across the five cross-validation folds.

To quantify PRS-related improvement, we calculated the difference in test performance between the full model and the corresponding null model for each tool and phenotype. Positive values therefore indicate improved predictive performance after inclusion of the PRS component, whereas negative values indicate no improvement relative to the null model. The full matrix of tool-specific improvements is shown in Table~\ref{TablePRSImprovement}.

At the phenotype level, the largest improvement was observed for Height, where the best-performing tool was LDAK-GWAS, increasing explained variance from 0.128 in the null model to 0.353 in the full model ($\Delta = 0.225$). Among binary phenotypes, the largest gain was observed for Depression, where LDAK-GWAS increased test AUC from 0.524 to 0.664 ($\Delta = 0.140$), followed by Asthma, where LDpred-2-Grid increased test AUC from 0.504 to 0.630 ($\Delta = 0.126$). For Irritable Bowel Syndrome (IBS), PRSice-2 improved test AUC from 0.589 to 0.678 ($\Delta = 0.089$), and for Migraine, XPBLUP increased test AUC from 0.540 to 0.629 ($\Delta = 0.089$).

Statistical significance of the improvement was assessed using paired fold-level comparisons between the null and full models. For each phenotype and tool, test performance across the five folds was compared using the Wilcoxon signed-rank test. In all five highlighted cases, the observed p-value was 0.0625. Although these improvements were consistent across folds, they did not cross the conventional significance threshold of 0.05. This is primarily a consequence of the small number of cross-validation folds ($n=5$), which limits statistical power and constrains the minimum attainable two-sided p-value.

Overall, these results indicate that PRS can provide meaningful improvement beyond baseline covariates for several phenotypes, particularly Height, Depression, and Asthma. However, inference regarding statistical significance should be interpreted cautiously because the limited number of folds reduces power even when the direction of improvement is consistent.

\subsection{Global Statistical Comparison of PRS Tools}
To determine whether differences in predictive performance across PRS tools were statistically significant, we performed a repeated-measures comparison across phenotypes. For each phenotype and cross-validation fold, the best-performing configuration of each tool was selected using the $\delta$-constrained criterion described earlier, which maximizes the combined training and test performance while constraining the train–test difference.

For each phenotype–fold combination, PRS tools were ranked based on their test-set performance (higher values indicating better predictive accuracy). This resulted in 40 independent datasets (8 phenotypes × 5 folds). Tools were then compared using the Friedman test, a non-parametric statistical test recommended for benchmarking multiple algorithms across multiple datasets.

When the Friedman test indicated significant differences, we performed post-hoc pairwise comparisons using the Nemenyi procedure. Pairwise comparisons were further adjusted for multiple testing using the Benjamini–Hochberg false discovery rate (FDR) correction. In addition, the critical difference (CD) statistic was calculated to determine whether differences in average ranks between tools were statistically meaningful.

Average ranks across datasets were used to identify the tools that consistently achieved the strongest predictive performance across phenotypes.

The Friedman test revealed a statistically significant difference in predictive performance among PRS tools across phenotypes ($\chi^2 = 102.29$, $p = 2.57 \times 10^{-11}$), indicating that the choice of PRS method significantly affects prediction accuracy.

Average ranking across the 40 phenotype–fold datasets identified several tools that consistently achieved strong performance. The top-performing tool was \textbf{LDpred2-Lassosum2} (average rank = 9.54), followed by \textbf{PRSice-2} (9.80) and \textbf{LDAK-GWAS} (10.22). Other methods frequently appearing among the top performers included PANPRS, GEMMA-LMM, Lassosum, GEMMA-LM, XPBLUP, C+T, and LDpred-inf.

Post-hoc Nemenyi comparisons revealed 34 pairwise differences exceeding the critical difference threshold, while 93 comparisons remained statistically significant after false discovery rate correction. LDpred2-Lassosum2 showed the strongest overall performance, achieving 10 statistically significant pairwise wins under the critical-difference criterion and 15 wins after FDR correction.

Despite these differences, no single PRS tool dominated across all phenotypes, highlighting the importance of evaluating multiple methods when constructing polygenic risk scores.

\subsection{Global comparison of PRS tools across phenotypes}
\label{sec:global_tool_comparison}

To identify the polygenic risk score (PRS) methods that perform consistently well across different phenotypes, we conducted a global statistical comparison of all evaluated tools. The comparison was performed using fold-level prediction performance obtained from five-fold cross-validation across eight phenotypes.

For each phenotype, each PRS tool was evaluated using the full predictive model (PRS + covariates + principal components). Within each fold, hyperparameter configurations were selected using a $\delta$-constrained criterion that maximizes the sum of training and test performance while restricting the train--test gap ($|Train - Test| < \delta$). The resulting configuration was used to obtain the fold-level test performance. 

To compare tools across phenotypes, we followed a standard benchmarking framework used in machine learning studies. For each phenotype and fold, PRS tools were ranked according to their test performance, with the best-performing tool receiving rank 1. Average ranks across all phenotype–fold combinations were then computed to measure the overall performance of each tool.

Statistical differences among PRS tools were assessed using the Friedman test, a non-parametric test designed for comparing multiple algorithms across multiple datasets. The Friedman test evaluates the null hypothesis that all tools have equivalent performance rankings. In our analysis, the Friedman test revealed a significant difference among tools ($\chi^2 = 102.43$, $p = 2.43 \times 10^{-11}$), indicating that PRS tool performance varies significantly across phenotypes.

Based on the average ranking analysis, the top-performing PRS tools were identified. Table~\ref{tab:top_tools} reports the ten tools with the best average ranks across all phenotypes. Lower average ranks indicate better overall predictive performance.

Overall, the results indicate that several methods consistently perform well across phenotypes. In particular, \texttt{PRSice-2}, \texttt{LDpred2-lassosum2}, and \texttt{LDpred2-grid} achieved the best average ranks, suggesting strong and consistent predictive performance across multiple traits. These tools therefore represent robust choices for polygenic risk prediction across diverse phenotypes.

\subsection{Structured Tool-Failure Analysis}

The categories include: \textit{installation failure}, \textit{dependency failure}, \textit{input-format incompatibility}, \textit{insufficient SNP overlap}, \textit{invalid heritability estimate}, \textit{phenotype-type incompatibility}, \textit{reference-panel requirement not met}, \textit{runtime/resource failure}, and \textit{missingness/genotyping-rate constraint}.

Most failures were not due to biological characteristics of the phenotype but instead arose from software constraints, input-data requirements, or computational limitations. Table~\ref{tab:prs_tool_failures} summarises the failure types observed across tools and phenotypes.

\subsection{Operational runtime, memory usage, and tool failure analysis}

In addition to predictive performance, we evaluated the operational characteristics of the PRS tools, including runtime, memory consumption, and failure rates across phenotypes. Across the expected 1,840 phenotype–tool–fold combinations, 1,499 execution logs were successfully recovered and provided at least one usable operational metric, corresponding to an overall usable log rate of 81.5\%.

\paragraph{Runtime and memory characteristics across tool families}

PRS tools were grouped into four methodological families: penalised regression, Bayesian models, multi-trait methods, and linear or linear mixed model approaches. Considerable variability in runtime and memory consumption was observed across these families (Table~\ref{tab:runtime_family_summary}). Penalised regression methods exhibited the lowest mean runtime (3,324 hours), whereas linear/LMM methods required the longest runtime on average (12,523 hours). Bayesian approaches showed the highest average memory consumption (3.50 TB), while multi-trait methods had the lowest mean memory footprint (1.78 TB).

\paragraph{Runtime variability across individual tools}

Substantial heterogeneity was also observed at the individual tool level. The fastest method was \texttt{VIPRS-Grid}, with a mean runtime of approximately 9 hours, followed by \texttt{GEMMA-LM} (16.4 hours) and \texttt{C+T} (47.2 hours). In contrast, several tools required extremely long runtimes due to complex optimisation procedures and hyperparameter exploration, with \texttt{CTPR} representing the slowest method in the benchmark (mean runtime 67,203 hours). Memory requirements also varied widely, ranging from approximately 274 GB for \texttt{CTPR} to more than 11 TB for \texttt{AnnoPred}.

\paragraph{Phenotype-level failure rates}

Tool execution failures were observed for several phenotypes (Table~\ref{tab:failure_rate}). Height exhibited a 0\% failure rate, with all tools completing successfully. In contrast, asthma had the highest failure rate (28.3\%), followed by gastro-oesophageal reflux (21.7\%), and several phenotypes including high cholesterol, hypothyroidism, and migraine (19.6\%). These failures primarily resulted from software constraints such as invalid heritability estimates, insufficient SNP overlap between GWAS summary statistics and genotype data, missing reference panels, or strict genotype completeness requirements.

\paragraph{Operational differences across phenotypes}

Operational performance also differed by phenotype. Height required the lowest average runtime (2,063 hours), whereas high cholesterol required the longest average runtime (10,683 hours). Memory requirements varied similarly: gastro-reflux had the lowest mean memory consumption (1.58 TB), whereas IBS required the highest memory usage (4.67 TB).

Together, these results highlight the substantial operational heterogeneity among PRS tools. While predictive performance remains a key evaluation metric, runtime, memory consumption, and software robustness represent important practical considerations when selecting PRS methods for large-scale genomic analyses.

# Results: Hyperparameter Sensitivity of PRS Performance

To evaluate whether predictive performance is influenced by model configuration, we performed a systematic hyperparameter sensitivity analysis across all PRS tools and phenotypes. For each tool, fold-level results were combined and all hyperparameters that exhibited variation were tested for association with held-out predictive performance using rank-based statistical tests. Hyperparameters were considered influential when variation in their values was significantly associated with changes in the predictive performance metric (\texttt{Test_best_model}). Effect sizes were quantified using Spearman correlation for numeric parameters or variance-based measures for categorical parameters, and uncertainty was estimated using bootstrap-derived 95\% confidence intervals (CI).

Overall, the analysis demonstrates that **PRS performance is frequently impacted by hyperparameter choices**, although the magnitude of this impact varies across tools and phenotypes. Several hyperparameters showed strong and statistically significant associations with predictive performance.

Across multiple tools, the **GWAS p-value threshold** emerged as one of the most consistently influential hyperparameters. For example, in AnnoPred, the p-value threshold strongly influenced predictive accuracy for the height phenotype (effect size = 0.72, 95\% CI: 0.67–0.76, (p = 2.8 \times 10^{-65})), indicating that model performance is highly sensitive to the inclusion threshold for variants. Similar patterns were observed for other methods such as BOLT-LMM and C+T, where the p-value threshold showed strong effects for height (effect size = 0.74, CI: 0.67–0.80, (p = 4.7 \times 10^{-53})) and C+T (effect size = 0.70, CI: 0.65–0.75, (p = 1.16 \times 10^{-75})). These results suggest that the optimal inclusion threshold for variants is a key determinant of predictive performance across multiple PRS construction strategies.

Another major driver of performance was the **number of variants included in the model**. For example, in BOLT-LMM the number of variants showed strong effects across several phenotypes, including gastro-oesophageal reflux (effect size = 0.84, CI: −0.88 to −0.76, (p = 1.25 \times 10^{-22})), high cholesterol (effect size = 0.87, CI: 0.85–0.87, (p = 4.9 \times 10^{-38})), and hypothyroidism (effect size = 0.88, CI: 0.86–0.89, (p = 3.5 \times 10^{-38})). These findings indicate that predictive performance in several PRS models is highly dependent on the effective number of SNPs incorporated into the score.

Similarly, **heritability-related parameters** influenced model performance in several Bayesian methods. In DBSLMM, the assumed trait heritability parameter was strongly associated with prediction accuracy in multiple phenotypes, including high cholesterol (effect size = 0.73, CI: −0.75 to −0.71, (p = 4.8 \times 10^{-102})) and irritable bowel syndrome (effect size = 0.71, CI: 0.64–0.78, (p = 1.53 \times 10^{-84})). These results highlight that the assumed genetic architecture encoded through the heritability parameter can substantially alter model behaviour.

For mixed-model approaches such as GCTA and GEMMA, multiple parameters showed significant associations with predictive accuracy. In GCTA, parameters including the number of variants, heritability estimates ((h^2)), and regularisation parameters (e.g., \texttt{gcta_lambda}) all demonstrated significant relationships with predictive performance across several phenotypes. For instance, in high cholesterol, the heritability parameter showed a strong association with predictive accuracy (effect size = 0.68, CI: −0.73 to −0.61, (p = 3.0 \times 10^{-43})). Similarly, in GEMMA-LM, the p-value threshold strongly influenced performance for height (effect size = 0.67, CI: 0.57–0.78, (p = 1.39 \times 10^{-14})) and IBS (effect size = 0.53, CI: 0.38–0.66, (p = 1.95 \times 10^{-7})).

In contrast, some tools exhibited relatively limited sensitivity to hyperparameter variation. For example, CTSLEB showed variation in p-value thresholds across phenotypes, but none of these parameters reached statistical significance for predictive performance. Similarly, some methods such as GCTB-SBayesRC showed variation in hyperparameters without a statistically significant effect on prediction accuracy. These results suggest that certain models are relatively robust to moderate changes in parameter settings.

Taken together, these results demonstrate that **PRS predictive performance is strongly influenced by several key hyperparameters**, particularly variant inclusion thresholds, the number of variants used in model construction, and parameters governing trait heritability or genetic architecture. However, the degree of sensitivity varies considerably between tools, with some methods showing strong dependence on parameter tuning while others remain relatively stable across the explored hyperparameter space. This highlights the importance of systematic hyperparameter optimisation when benchmarking or deploying PRS models.

 

\subsection*{Predictive performance varies substantially across tools and phenotypes}

We evaluated 46 PRS tools across eight phenotypes (Table~\ref{dataset}) and report performance as AUC for binary phenotypes and explained variance ($R^{2}$) for Height (Table~\ref{Table1Results}). Per-phenotype best performers were: LDpred-gibbs for asthma (AUC~=~0.60), LDAK-GWAS for Height ($R^{2}$~=~0.40), PolyPred for depression (AUC~=~0.64), BOLT-LMM for gastroesophageal reflux (AUC~=~0.74) and hypothyroidism myxoedema (AUC~=~0.67), PRSice-2 for high cholesterol (AUC~=~0.93), MTG2 for irritable bowel syndrome (AUC~=~0.68), and GEMMA-LM for migraine (AUC~=~0.60). These results are consistent with prior observations that PRS performance is trait-specific and sensitive to cross-validation design and genetic architecture~\cite{Ma2021}.

To summarise cross-phenotype patterns without conflating AUC and $R^{2}$ through summation, we counted how many times each tool appeared among the top five performers per phenotype (Figure~\ref{Figure1}a). GEMMA-LM appeared most frequently (four phenotypes), followed by BOLT-LMM, PRSice-2, MTG2, LDpred-fast, and XP-BLUP (three phenotypes each). No tool was uniformly optimal across all eight phenotypes, and performance differences among the majority of tools were modest and highly variable by trait. These results should be interpreted as descriptive summaries of relative ranking patterns rather than evidence of statistically established superiority.

\subsection*{PRS contribution over covariate-only models}

To distinguish performance attributable to the PRS from that arising from the covariate structure, we compared three model configurations for each tool and phenotype: (1)~a null model using only PCA components and demographic covariates; (2)~a pure PRS model using only the polygenic score; and (3)~a full model combining PRS with all available covariates (Figure~\ref{Figure1}b; Supplementary Table~S3). For Height, the pure PRS model explained substantially more variance than the null model for the best-performing tools, confirming a genuine genetic signal. For binary phenotypes, the null model already captured meaningful predictive information from 135 NMR metabolomic biomarkers and comorbidity covariates, and the incremental contribution of PRS over the null model varied markedly by phenotype and tool. The values reported in Table~\ref{Table1Results} reflect the full model; pure PRS performance for all phenotypes is provided in Supplementary Table~S3. This distinction is important: apparent tool superiority in the full model may partly reflect interaction between the PRS and covariate structure rather than inherent methodological differences between tools.

\subsection*{Hyperparameter sensitivity and overfitting behaviour}

As the p-value threshold increased, training performance improved for most tools (Figure~\ref{Figure1}c). Tools such as GEMMA-LM, GEMMA-LMM, and XP-BLUP maintained high performance at low p-values, consistent with overfitting on the training genotype data. Tools such as AnnoPred, Plink, and PleioPred showed more gradual and consistent performance increases with higher p-values. LDAK-GenotypeData, BOLT-LMM, GEMMA models, and MTG2 showed larger train--test gaps, suggesting overfitting. By contrast, GCTA, Lassosum, LDpred-2, PRScs, and VIPRS showed the lowest performance variation across folds, indicating greater stability on continuous phenotypes. Combining pure PRS with covariates improved both training and testing performance across most tools and phenotypes.

\subsection*{Beta-value correlation structure reflects methodological families}

PRS tools cluster by their beta-value correlation structure in multidimensional scaling (MDS) and hierarchical clustering analyses (Figure~\ref{Figure1}d,e). Tools that rely on training genotype data cluster closely together. LDpred-based tools (LDpred2\_inf, LDpred2\_grid, LDpred2\_auto, LDpred2\_lassosum2) form a tight group, as do PleioPred, AnnoPred, Lassosum, and LDAK. Bayesian approaches (DBSLMM, GCTB-SBayesR, GCTB-SBayesRC) show weaker correlations with linear-model-based tools (Plink, PRSice-2), while Lassosum, GCTB-SBayesR, and LDAK-GWAS show strong positive correlations with each other. LDpred2 variants show negative correlations with several other tool families. These patterns reflect methodological differences between linear and Bayesian approaches and provide a basis for understanding tool complementarity and redundancy (Supplementary Material, \textbf{Beta's Correlation -- Height}). Tools using all SNPs ($p$-value~=~1), such as LDAK-GWAS and Lassosum, tend to show higher explained variance for Height, while selective SNP approaches such as JAMPred and BOLT-LMM also perform competitively.

\subsection*{Computational efficiency}

GEMMA-LM was the most computationally efficient tool (0.023 hours, 1.79~MB peak memory), making it suitable for high-throughput and memory-constrained analyses. HAIL required the longest runtime (36.37~hours), and PleioPred required 14.03~hours with 34.41~MB peak memory. Full runtime and memory data for all tools on the Height phenotype are provided in Supplementary Material (\textbf{Execution Time -- Height}).

\subsection*{Implementation failures are informative and common}

A substantial number of tools failed under at least one phenotype condition, as indicated by NaN entries in Table~\ref{Table1Results}. Failure modes fell into five categories: (1)~insufficient SNP overlap between the GWAS and genotype data, affecting tools with strict SNP-matching requirements (NPS, CTPR) particularly for binary phenotypes where as few as 461--482 common SNPs were available (Table~\ref{dataset}); (2)~heritability estimates outside valid bounds (BOLT-LMM); (3)~genotyping-rate requirements that could not be met under standard QC (NPS, CTPR require rate~=~1); (4)~phenotype-type incompatibility (PleioPred is restricted to continuous phenotypes); and (5)~dependency on large external reference panels not available for all configurations (GCTB). These failure patterns are not incidental: they reflect fundamental assumptions embedded in each tool's design and are directly relevant to deployment decisions. Full failure classification and implementation notes for all tools are provided in Supplementary Table~S2 and online documentation (\url{https://muhammadmuneeb007.github.io/PRSTools/Introduction.html}).


\subsection{Phenotype dependence of PRS tool performance}

To determine whether PRS tool performance was consistent across traits, we re-analysed the selected fold-level results by ranking tools within each phenotype-fold dataset according to held-out predictive performance (\texttt{Test\_best\_model}). This ranking-based approach enabled direct comparison across both binary and continuous phenotypes despite differences in scale between AUC and explained variance.

The global Friedman test showed that tool rankings differed significantly across phenotype-fold datasets ($\chi^2 = 102.29$, $p = 2.57 \times 10^{-11}$), indicating that PRS tool performance was strongly phenotype-dependent. Consistent with this, the top-ranked tool was not constant across traits: across the eight evaluated phenotypes, seven different tools emerged as the phenotype-specific top performer. The leading methods were LDpred-2-Grid for Asthma, LDAK-GWAS for Depression and Height, GEMMA-BSLMM for Gastro-Reflux, PRSice-2 for High Cholesterol, LDpred-inf for Hypothyroidism, XPBLUP for IBS, and GEMMA-LM for Migraine.

Further evidence for phenotype dependence was observed at the individual-tool level. Several methods showed large shifts in relative ranking across phenotypes, including GEMMA-LMM (rank range = 40.3), XPBLUP (38.7), GEMMA-LM (37.1), HAIL (33.8), and MTG2 (33.5). For example, GEMMA-LMM and GEMMA-LM ranked among the strongest methods for Migraine but performed much less competitively for Height, while XPBLUP ranked highly for High Cholesterol and IBS but poorly for Height. These results indicate that the comparative performance of PRS tools is highly context-dependent and varies substantially across phenotypes.
\subsection{Similarity of SNP effect-size profiles across PRS tools}

To assess whether different PRS methods produced similar SNP effect-size profiles, we compared the beta values generated by each tool across phenotypes. For each phenotype, beta estimates were averaged across the five cross-validation folds for each tool, aligned on overlapping SNPs, and used to compute pairwise Pearson correlations between tools. These phenotype-specific correlation matrices were then averaged across phenotypes to obtain an overall cross-phenotype similarity matrix.

This analysis showed that PRS tools differed substantially in the extent to which they produced similar SNP effect-size patterns. Several tools clustered closely, indicating that they generated highly concordant beta profiles across phenotypes, whereas other tools were more distinct and formed separate groups. In general, methods based on related modelling assumptions tended to show greater similarity to one another, while tools based on different shrinkage strategies, mixed-model formulations, or multi-trait frameworks were more dispersed. The heatmap, multidimensional scaling (MDS) representation, and hierarchical dendrogram together demonstrate that PRS tools do not simply differ in predictive accuracy, but also in the structure of the SNP effect sizes they produce. This indicates that tools with similar predictive performance may still derive risk scores from substantially different effect-size architectures.




\section*{Discussion}

This study presents a harmonized benchmarking framework for the comparative evaluation of 46 polygenic risk score (PRS) tools across multiple phenotypes. The framework standardizes data preprocessing, tool execution, hyperparameter exploration, and evaluation procedures, enabling a consistent comparison of diverse PRS methodologies. Our results demonstrate that PRS tool performance is strongly phenotype-dependent, with different tools performing optimally under different trait architectures and modelling conditions. This finding reinforces observations from previous studies that no single PRS method universally outperforms all others, highlighting the importance of evaluating multiple tools when constructing PRS models.

Beyond predictive accuracy, the benchmarking framework also captures operational characteristics that influence practical tool deployment. Substantial variation was observed in runtime, memory consumption, and execution robustness across PRS tools. Some tools completed analyses within minutes, whereas others required several hours of computation or substantial memory resources. Similarly, several methods failed under specific data conditions due to strict input requirements, reference panel dependencies, or unstable heritability estimates. These results emphasize that operational considerations—including computational efficiency, installation complexity, and robustness to real-world data—are important factors when selecting PRS tools for large-scale genomic analyses.

The study also highlights the importance of standardized benchmarking design. By applying a unified preprocessing pipeline and consistent cross-validation strategy, the framework minimizes methodological inconsistencies that often complicate comparisons between PRS methods. The inclusion of hyperparameter exploration further provides insight into how parameter choices influence predictive performance. In practice, PRS accuracy can vary substantially depending on parameter settings, data preprocessing decisions, and covariate structures, and therefore benchmarking frameworks should evaluate these factors systematically.

Several limitations should be acknowledged. First, the benchmarking was performed across a limited number of phenotypes and datasets, which may restrict the generalizability of the observed performance patterns. Second, deeper methodological analyses were primarily conducted for the continuous Height phenotype, although the framework itself can be readily applied to other traits. Third, differences in software requirements and input assumptions among tools make perfectly uniform benchmarking challenging, despite the standardized execution framework used in this study. Future work could extend the benchmarking framework to additional phenotypes, larger cohorts, and more diverse ancestry groups in order to further evaluate the robustness and generalizability of PRS tools.

Overall, the proposed framework provides a structured and reproducible platform for comparative PRS tool evaluation. By integrating predictive performance metrics with operational characteristics such as runtime, memory usage, and software robustness, the framework offers a more comprehensive perspective on PRS tool performance and usability.

\section*{Conclusion}

In this work, we developed and applied a harmonized benchmarking framework for the implementation-aware evaluation of polygenic risk score tools. Using standardized preprocessing, cross-validation, and unified evaluation procedures, we benchmarked 46 PRS tools across binary and continuous phenotypes. The results demonstrate that PRS tool performance varies substantially across phenotypes and analysis settings, indicating that tool selection should be guided by the characteristics of the target dataset rather than by a single universally preferred method.

To ensure full reproducibility of the benchmarking framework, all analyses were executed using Conda-managed environments with explicitly defined software versions. Because several PRS tools require incompatible dependencies and different language versions, the workflow was organized into five dedicated environments: \texttt{genetics} (Python~3.10, R~4.3), \texttt{ldscc} (Python~2.7), \texttt{advanceR} (R~4.3), \texttt{polyfun} (Python~3.10), and \texttt{viprs\_env} (Python~3.10, R~4.3). Each environment is defined through a version-controlled \texttt{environment.yml} configuration file specifying all package dependencies required for tool execution. Replication instructions and environment configuration files are provided with the framework to allow the complete computational setup to be recreated.

Several methods were evaluated but excluded from the final benchmarking due to practical limitations. \textit{Multiprs} represents a methodological framework rather than a standalone tool, \textit{BGLR-R} returned NaN explained variance values across all phenotypes despite correct input formats, and \textit{PolyRiskScore} is a web-based platform with limited flexibility for large-scale benchmarking. In addition, \textit{FairPRS} does not support parallel execution across datasets on HPC systems, and \textit{RapidoPGS-multi} does not support continuous phenotypes.

Taken together, this study provides a reproducible benchmarking resource that highlights both predictive and operational differences among PRS tools. The proposed framework can serve as a foundation for future comparative studies and may assist researchers in selecting and evaluating PRS methods for diverse genomic applications.
