
\subsection{Automatic Analysis}
\subsubsection{BLEU}
We analyze the output of our system using BLEU \cite{papineni2002bleu} on all 16 scenarios and report a per-scenario mean in Table \ref{table:bleu}.
In order to draw any conclusion if a specific component improves or worsen the BLEU score, we average all cells where that component appeared, and compare to the cells where that component didn't appear.
We find that using the verification component increases BLEU by 0.1, the REG component increases by 0.59, the Neural Planner worsen by 0.19, and the typing information worsen by 0.55.

\subsubsection{Coverage}
To evaluate how much the typing information helps the decoding process to include all entities, we measure the entity order coverage for realizations of best plans (from both the naive or neural planners). Using the typing information reduced the number of generated sentences with mismatched entity sequences by 18\% for the seen part and by 16\% for the unseen part. % (Ablation in Table \ref{table:coverage}).

When using the verification process instead of the best plan, comparing the number of mismatched sequences is less meaningful, as the verification process optimizes for no mismatches. Instead, we evaluate how many plans were required to realize in order to get a perfect coverage. Using the typing information reduced this number from 1.13 to 1.11 for the seen part of the test set, and from 7.2 to 5.8 on the unseen part. 


\subsection{Manual Analysis}
\subsubsection{Output Verification and Typing}
In order to measure the effect of the verification and typing components, we replicate the manual evaluation proposed in \citet{step-by-step}. We call this model BestPlan+. The original system had 23 correctness errors (out of 440 relations). Adding the verification step reduced the number to 14, fixing all 3 hallucinations and all 6 omissions, and fixing 3 wrong lexicalizations.   

We further evaluate the system including all components, which we call BestNeuralPlan+. The main advantage of this system is that the neural planner is 4.8 orders of magnitude faster than the original exhaustive one. This however comes with a price in accuracy: BLEU scores drop by 0.05 points on average compared to the original system, and the number of correctness errors (verified manually) goes up to 35 (fixing 4 out of six omissions, but having 4 hallucinations and 30 wrong lexicalizations).

\subsubsection{Referring expressions} We manually reviewed pairs of entities and referring expressions generated by the system. We found the system manages to refer correctly 92.2\% of the time. Overall, 27.6\% are correct pronouns, 16.3\% are predicting to repeat the entity, given it contains one word, 2.25\% of the cases failed to find a valid replacement, therefore fell back on repeating the entire entity, and 7.8\% of the cases were wrong referrals. This concludes with 73.3\% of the repetitions being replaced with a more fluent expression.
